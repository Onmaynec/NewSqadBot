


## Discord Web Portal — удалённый доступ сотрудников

Веб-портал авторизует Owner, Admin, Moder и Ticket Staff через Discord OAuth2 и проверяет реальные роли сервера при каждом запросе. Можно использовать домашний ПК без собственного домена через Tailscale Funnel и HTTPS.

Доступны заявки с одобрением/отказом и историей, тикеты с перепиской из Discord, состав сотрудников, участники, модерационные дела, статистика, рейтинги, аудит и активность администрации. Настройки бота доступны **только Owner**.

Полная инструкция: [docs/WEB_PORTAL.md](docs/WEB_PORTAL.md).

**Важно:** в OAuth-режиме парольный вход отключается. Пока в .env не указаны WEB_DISCORD_CLIENT_ID, WEB_DISCORD_CLIENT_SECRET и WEB_PUBLIC_URL, сайт остаётся локальным с прежним парольным входом. Для публичного HTTPS-доступа требуется отдельная настройка Funnel, по умолчанию сайт не открывается в интернет.
