


## Discord Web Portal — удалённый доступ сотрудников

Веб-портал авторизует Owner, Admin, Moder и Ticket Staff через Discord OAuth2 и проверяет реальные роли сервера при каждом запросе. Можно использовать домашний ПК без собственного домена через Tailscale Funnel и HTTPS.

Доступны заявки с одобрением/отказом и историей, тикеты с живой перепиской из Discord, список участников и staff, ручные модерационные наказания и управление делами, статистика, рейтинги и аудит. Для Admin доступны мероприятия, розыгрыши, предложения и голосовые комнаты; для Owner дополнительно — редакторы товаров NS Coins, панелей выбора ролей, авторолей, категорий поддержки и объявлений. **Только Owner** может менять конфигурацию бота. Все операции защищены серверными проверками ролей и CSRF.

Полная инструкция: [docs/WEB_PORTAL.md](docs/WEB_PORTAL.md).

**Важно:** в OAuth-режиме парольный вход отключается. Пока в .env не указаны WEB_DISCORD_CLIENT_ID, WEB_DISCORD_CLIENT_SECRET и WEB_PUBLIC_URL, сайт остаётся локальным с прежним парольным входом. Для публичного HTTPS-доступа требуется отдельная настройка Funnel, по умолчанию сайт не открывается в интернет.

## v1.7.0 — Support Quality & Live Operations

- **Добровольные оценки поддержки** в DM после удаления закрытого тикета: 1–5, одно голосование, срок 7 дней, анонимизация Discord ID участника после оценки; переписка и содержание обращения не сохраняются.
- **Live Dashboard** на главной странице: очереди заявок/тикетов, живое состояние Discord/SQLite/Scheduler/EventBus, сотрудники онлайн только при Presence Intent, последние действия администрации в рамках RBAC.
- **Центр уведомлений**: новые заявки, назначенные тикеты, ошибки выдачи роли, предстоящие мероприятия; личная отметка прочитанного, оповещения не раскрывают приватное содержимое.
- Новая миграция SQLite `0015_support_live_ops`; существующие функции остаются совместимы с Docker Compose.
