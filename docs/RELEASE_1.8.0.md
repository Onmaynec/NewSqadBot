# NewSqadBot v1.8.0 — Obsidian Web Console

Версия посвящена обновлению **веб-панели** NewSqad. Визуальная система полностью переведена на монохромную палитру Obsidian; основные рабочие сценарии поддержки, заявок и навигации дополнительно переработаны.

## Интерфейс

- Почти чёрный фон, белый основной текст, тонкие границы и сдержанная анимация. Крупные декоративные элементы уступили место рабочим данным.
- Обновлены общие стили Dashboard, заявок, тикетов, персонала, модерации, аналитики, аудита, мероприятий, магазина, редакторов и настроек.
- Боковое меню разбито на блоки: рабочая область, управление, аналитика, конфигурация, система.
- Глобальная палитра Ctrl/Cmd + K ищет разрешённые разделы. Для Owner дополнительно ищет настройки по имени, ключу и группе. Ролевая защита остаётся серверной.
- Везде поддерживается уменьшенное движение (prefers-reduced-motion). Адаптивная компоновка рассчитана на телефон, планшет и десктоп.
- Диалоги подтверждения, ввода и передачи тикетов удерживают фокус внутри окна, закрываются Escape и возвращают фокус после закрытия. Предупреждение о несохранённых изменениях также поддерживает клавиатуру.

## Заявки

- Фильтрация по статусу, поиск по имени кандидата, Discord-имени, Discord ID и номеру заявки на сервере.
- Пагинация по 100 записей, общий счётчик, сообщение об отсутствии результатов, кнопка повторной загрузки.
- Поисковые запросы отправляются с задержкой 320 мс; устаревшие ответы не перерисовывают новый поиск.
- Решения по заявкам и проверки доступа работают через прежние API.

## Тикеты

- Глобальная серверная фильтрация «Все», «Без ответственного», «Мои» и «В работе». Личный фильтр требует входа через Discord OAuth.
- Поиск по теме и номеру тикета, сортировка по последней активности, пагинация и точные счётчики.
- Нельзя случайно отправить два действия одновременно. При временной ошибке Discord старые сообщения на экране не исчезают — выводится состояние синхронизации.
- Перед выходом из тикета с неотправленным ответом появляется предупреждение. Черновик **не** записывается в LocalStorage, SQLite и логи.
- Приватные сообщения загружаются из Discord при открытии тикета. После удаления канала сообщения не архивируются.

## Live Dashboard

- Добавлены быстрые действия для перехода к очереди заявок, тикетам и уведомлениям.
- Индикатор состояния теперь зависит от доступности Discord Gateway, SQLite, Scheduler, EventBus и ошибок модулей.

## Обратная совместимость

- Старые поля JSON **items** в API списков сохранены.
- В GET /api/portal/applications добавлены page и q.
- В GET /api/portal/tickets добавлены page, q и assignment=all|unassigned|assigned|mine.
- Оба списка отвечают page, page_size, total, has_next; неизвестные фильтры и некорректные параметры дают HTTP 400.
- Поиск ограничен 80 символами. Спецсимволы SQL LIKE (% и _) воспринимаются буквально, без широкого поиска по шаблону.
- Сайт по-прежнему работает с одним Discord-сервером. Модель Discord OAuth/ролей, ограничения на сохранение переписок и команды бота не менялись.
- Миграция базы данных **не требуется**.

## Проверка и установка

CI выполняет Ruff, Python compileall, pytest, синтаксическую проверку JavaScript и Docker smoke. Дополнены тесты пагинации, поиска и изоляции по guild. Запуск и обновление прежние:

```powershell
git pull origin main
docker compose up -d --build --force-recreate
docker compose logs --tail=150 bot
```

До использования новой панели в рабочей среде проверить доступ под Owner, Admin, Moder и Ticket Staff, выдачу прав и удаление тестового тикета в Discord, вход OAuth и страницу на мобильном устройстве. Подробный список — docs/WEB_OBSIDIAN.md.

**Ограничения этого релиза:** старые CSS и JS пока оставлены для совместимости и переопределяются отдельным слоем Obsidian. Полная замена всей внутренней бизнес-архитектуры бота в v1.8.0 не выполнялась. Это релиз веб-консоли, а не переписывание всех Discord-модулей.
