# NewSqadBot v1.7.0 — Support Quality & Live Operations

В версии добавлены добровольные оценки поддержки, живой обзор сервера и центр уведомлений веб-панели.

## Оценка поддержки

После **успешного удаления** Discord-канала тикета и очистки всех его данных бот создаёт минимальную запись приглашения на оценку и пытается отправить автору личное сообщение с кнопками **1–5 звёзд**. Опрос добровольный, действует 7 дней, каждое приглашение можно оценить **только один раз**. После оценки Discord ID автора в записи заменяется на 0. Опросы без ответа удаляются при истечении срока.

**Приватность:** в таблице `support_surveys` нет текста сообщений, темы, описания, причин закрытия, транскрипта и идентификатора закрытого тикета. Остаются только оценка, временная метрика, ID назначенного сотрудника и дата. Уведомления о назначении тикета удаляются вместе с записью тикета.

**Метрика первого ответа:** время между созданием тикета и первым фактическим ответом сотрудника; простое нажатие «Взять в работу» больше не считается ответом. Если сотрудник ответил, не нажимая «Взять в работу», он автоматически становится ответственным. Средняя скорость ответа считается по **всем закрытым тикетам с реальным ответом**, включая те, которые не были оценены. Неразрешённые/неотвеченные тикеты отдельно учитываются в числе закрытых.

Доступ к разделу «Качество поддержки» — только **Owner** и **Admin**. На сайте есть средняя оценка, количество оценок, доля оценок 4–5, среднее время первого ответа, а также показатели по сотрудникам за 7, 30 и 90 дней.

Если пользователь закрыл личные сообщения, опрос не отправляется. Сбой доставки оценки **не отменяет закрытие тикета**. Неполученные приглашения повторно обрабатываются при старте и с периодическим обслуживанием.

## Live Dashboard

Главная страница автоматически обновляется примерно раз в 20 секунд и показывает:

- Число открытых тикетов и заявок, ожидающих рассмотрения.
- Доступность Discord Gateway, SQLite, Scheduler и EventBus.
- Сотрудников с ролями на сервере и статусами (при наличии Presence Intent).
- Количество сотрудников в сети. Если Presence Intent не подключён, показано **«Статусы недоступны»**, а не ложное «офлайн».
- Для Owner и Admin — последние административные действия **без приватных подробностей**.

Для Owner новый Live Dashboard встроен в прежнюю главную страницу с аватаром/баннером сервера; для остальных сотрудников доступен раздел «Обзор».

## Центр уведомлений

Значок колокольчика в верхней панели и раздел «Уведомления», обновление примерно раз в 30 секунд. Источники:

- **Новая заявка:** уведомление всем staff с доступом к заявкам.
- **Назначенный тикет:** только конкретному сотруднику, которому назначено обращение.
- **Ошибка выдачи роли:** только Owner/Admin.
- **Скоро мероприятие:** Owner/Admin, если до начала осталось не более 1 часа.

Уведомления можно читать по одному или пометить все прочитанными. Прочитанность привязана к **Discord ID сотрудника**, а не к общей cookie/устройству. При снятии staff-роли доступ сразу блокируется через обычный OAuth/RBAC. Источники дедуплицируются на уровне SQLite; подробности заявок/переписок не копируются в уведомления. Срок хранения уведомлений — 30 дней. При удалении тикета удаляются и его уведомления о назначении.

**Важно:** для уведомлений требуется вход в сайт **через Discord OAuth**. Локальный пароль без Discord-аккаунта не используется для персональных уведомлений.

## Обновление

```powershell
git pull origin main
docker compose up -d --build --force-recreate
docker compose logs --tail=150 bot
```

Миграция `0015_support_live_ops` запускается автоматически при старте. Данные о действующих заявках и тикетах сохраняются; тексты уже закрытых обращений по-прежнему не архивируются.

Для онлайн-статусов в `.env` требуется `ENABLE_PRESENCE_INTENT=true` и Presence Intent в Discord Developer Portal. Для чтения чата тикетов требуется Message Content Intent, как и раньше.

## Проверка после установки

- [ ] Закрыть тестовый тикет, проверить удаление Discord-канала и SQLite-записи.
- [ ] Получить опрос в ЛС, поставить 1–5, убедиться, что повторное голосование запрещено.
- [ ] Перезапустить бота при существующем опросе и проверить работу прежних кнопок.
- [ ] Выключить ЛС: закрытие тикета всё равно должно завершиться.
- [ ] Проверить отображение статистики по поддержке только у Owner/Admin.
- [ ] Проверить обновление главной страницы после новых заявок/тикетов.
- [ ] Подтвердить, что без Presence Intent статусы не выдаются за достоверные.
- [ ] Проверить уведомления для четырёх ролей; назначенный тикет видит только адресат.
- [ ] Проверить CSRF для отметки прочитанного и отзыв доступа после снятия роли.
- [ ] Проверить, что у удалённого тикета больше нет ссылок в уведомлениях.

Автоматический CI проверяет код и контейнер, но не заменяет ручной прогон на реальном Discord-сервере с несколькими тестовыми аккаунтами.
